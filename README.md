# Neon Maze

A small dependency-free first-person 3D maze game written in Python. Collect all four signal crystals, then reach the green exit.

## Run

```powershell
python askdaddy.py
```

## Controls

- `WASD` or arrow keys: move and turn
- `Q` / `E`: turn left / right
- `Space`: restart after winning
- `Esc`: quit
